Project Description

The Password Strength Checker is a Python-based project that checks the strength of a password based on different security rules.

It classifies passwords into three categories:

- Weak
- Medium
- Strong

It also provides suggestions to improve password security.

Features

1. Checks minimum 8 characters.
2. Checks uppercase letters.
3. Checks lowercase letters.
4. Checks digits.
5. Checks special characters.
6. Displays password strength out of 5.
7. Provides suggestions for improvement.
8. Rejects empty passwords and spaces.

Technologies Used

- Python 3
- Regular Expressions (re module)
- VS Code

How to Run

1. Install Python 3.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the following command:

python "password strenght checker.py"

5. Enter a password to check its strength.

Expected Output

- Weak (0–2)
- Medium (3–4)
- Strong (5)

Conclusion
